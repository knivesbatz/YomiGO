# What YomiGo takes from other tools

These summaries are in YomiGo's own words. Nothing here copies code, text, or interface from these projects.

| Source | Idea | Status |
|---|---|---|
| **Yomitan** | Pop-up dictionary from selected text, with inflection handling | Adapted, course words only. Full dictionaries deferred |
| **Yomitan** | Saving sentences with a word | Adopted in Reader |
| **Mokuro** | OCR that makes manga text selectable | Deferred to 0.3 |
| **LunaTranslator** | Capturing game text, with swappable translation providers | Deferred to 0.3 |
| **GameSentenceMiner, anki_miner** | Mining flashcards from what you're playing or watching | Deferred to 0.3, by owner's request |
| **Anki** | Spaced repetition, review history | Adopted: integer SM-2 |
| **Anki** | Import and export | Adapted: TSV export from Reader. More deferred |
| **Duolingo** | Short lessons, streaks, XP | Adopted |
| **Duolingo** | Leagues and social features | Excluded for now: this is for two people |
| **Duolingo** | Speaking checks | Adapted on Android: compares what the recogniser heard |
| **Quizlet** | Multiple study modes on one set | Adapted: choice, reverse choice, typing |
| **Quizlet** | Matching games | Deferred |
| **WaniKani** | Mnemonics for each kanji | Adapted: YomiGo writes its own |
| **WaniKani** | Radicals, then kanji, then vocabulary, in fixed order | Deferred: kanji are taught in themed sets today |
| **Canvas-style courses** | A daily class with a clear checklist | Adopted |
| **User's guides** (DJT, Japanification, AJATT, and others) | Daily immersion, early native media, and consistency | Adopted as daily immersion tasks and the Library |
